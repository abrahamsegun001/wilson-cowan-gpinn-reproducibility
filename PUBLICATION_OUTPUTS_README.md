# Publication results pipeline

This package does **not retrain** the Wilson-Cowan gPINN. It turns the completed
Narval experiments into the exact tables, master data files, and figures used
for the revised manuscript.

## Scripts

- `extract_publication_results.py` — one source of truth for numerical results.
- `make_publication_tables.py` — renders extracted CSV tables to Markdown and LaTeX.
- `make_publication_figures.py` — generates Figures 1–5 from the same master results.
- `job_publication_outputs.sh` — Narval job that runs all three in order.

## Main tables

1. `table1_final_pipeline_hyperparameters` — final architecture, inference,
   model-selection and training settings.
2. `table2_synthetic_recoverability` — known-truth synthetic inverse evidence,
   including the original joint-gPINN failure and derivative/regression controls
   when those completed synthetic outputs are present on Narval.
3. `table3_real_session_summary` — final 20-chunk resting-state model-selection,
   physical-parameter, interpolation, PDE, and continuity summary.

## Supplementary tables

- S1: all 20 final chunk-wise estimates and diagnostics.
- S2: model-selection criteria by chunk.
- S3: continuity-loss ablation summary.
- S4: matched sequential-vs-independent state reconstruction comparison.

Each table is saved as `.csv`, `.md`, and `.tex`.

## Main figures

1. Final method schematic.
2. Synthetic parameter/derivative validation.
3. Real-session model selection and parameter estimates.
4. Representative observed/predicted reconstruction, time trace, scatter, and PDE residual.
5. Sequential state-transfer and continuity evidence.

Figures are saved as both PDF and 300-dpi PNG.

## Important design principle

Tables and figures are **not generated by separate numerical analyses**. Both
consume the same `outputs/publication/master/` files produced by the extraction
script. This prevents the manuscript table values and plotted values from
silently diverging.
