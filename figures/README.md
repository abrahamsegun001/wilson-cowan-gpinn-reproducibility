# Static manuscript figures

These PNGs are included as a convenient snapshot of the manuscript figures. The repository also includes the plotting code required to regenerate them after the corresponding experimental outputs have been reproduced.

Figure 2 received only a terminology cleanup in this archive (`Baseline joint gPINN` in the legend); plotted numerical values and graphical marks were not changed. Regeneration from the publication pipeline is preferred over relying on the static raster.
